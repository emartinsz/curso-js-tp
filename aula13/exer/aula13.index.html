/* Resumo sobre strings: - Os índices começam em 0. Ex.: "Pedro" P = 0, e = 1, d = 2, r = 3, o = 4 - nome.length informa a quantidade de caracteres. Ex.: "Pedro".length = 5 - nome[1] acessa o caractere que está no índice 1. - nome.slice(-3) retorna os últimos 3 caracteres da string. - nome.indexOf('a') retorna o índice da PRIMEIRA ocorrência de 'a'. - nome.lastIndexOf('a') retorna o índice da ÚLTIMA ocorrência de 'a'. - Se indexOf() ou lastIndexOf() não encontrarem o caractere, retornam -1. - JavaScript diferencia letras maiúsculas de minúsculas. 'A' é diferente de 'a'. */
